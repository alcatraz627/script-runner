## UIs

### 1. Image Selection Dashboard (existing — port 3458)

The image-selector dashboard already exists. We load a **new dataset** (`jegs-final-images`) with the 602 items' updated image lists. You browse a grid of products, click through image carousels, and **pin** the main image for each item.

**No code changes to the dashboard itself.** Just a new dataset generated by a script.

### 2. Attribute Review Table (new — self-contained HTML)

A **new single-file HTML page** (`attribute-review.html`) for reviewing all 602 items' attributes in your browser. No server needed.

**Features:**
- Table with SKU, Part Type, source (excel/extracted), attribute name-value pairs, quality flags
- **Color coding**: red = flagged bad, yellow = needs review, green = clean
- **Inline editing** — click any value to edit it
- **Delete/add** individual attribute pairs per item
- **Approve/reject** checkboxes per item
- **Filters** — by flag type, source, SKU search, flagged-only/clean-only toggle
- **Bulk actions** — approve all clean, reject all flagged, strip eBay metadata from all
- **Export button** — downloads `approved.json` ready for pipeline injection
- **Stats bar** — total, flagged, approved, rejected counts
